# Treasure Time

Web app for the Treasure Time project: complete everyday tasks, earn minutes of time for yourself,
use them and register the moment. Phase 1 scope and acceptance criteria are in the project's SOW v3.3
(portfolio repo). Data is saved only in the browser (`localStorage`).

- Stack: React + Vite + Tailwind CSS
- All app copy (es-AR) is in `src/copy.js`
- Published to GitHub Pages from `master` (`.github/workflows/deploy.yml`)

```
npm install
npm run dev
```

The August 2026 Expo + Firebase plan is archived in `docs/archive/` (obsolete since SOW v3.2).
